# YouTube 음원 → 악보 추출 앱 — 기획 (2026-10-16 사용자 제공 원문)

> 사용자가 대화에 붙여 넣은 기획을 그대로 옮겼다. 검토 의견과 결정은 [`../BACKLOG.md`](../BACKLOG.md) 에 적는다.

## 1. 개발 파이프라인 (핵심 아키텍처)

YouTube 링크 입력부터 악보 출력까지의 핵심 기술 단계입니다.

[YouTube URL 입력] ➡️ [오디오 추출/분리] ➡️ [AI 음고·리듬 분석(AMT)] ➡️ [악보 렌더링/편집] ➡️ [파일 내보내기]

- **오디오 다운로드 및 전처리**: 사용자가 입력한 YouTube URL에서 오디오 데이터(MP3, WAV 등)를 안정적으로 추출하는 모듈이 필요합니다.
  주의: YouTube 오디오는 가변 비트레이트(VBR) 등으로 압축되어 배음 정보가 손실될 수 있으므로, AI 모델 입력 전에 오디오 정규화(Normalization) 과정이 필수적입니다.
- **음원 분리 (Audio Separation)**: 복잡한 밴드 음악이나 보컬이 섞인 음원은 채보 정확도가 급격히 떨어집니다.
  Spleeter나 Demucs 같은 AI 모델을 활용해 피아노, 기타, 보컬, 베이스, 드럼 등으로 오디오 트랙을 먼저 분리(Stem Separation)해야 채보 정확도를 높일 수 있습니다.
- **자동 음악 채보 (AMT - Automatic Music Transcription)**: 분리된 오디오를 입력받아 음높이(Pitch), 리듬(Onset/Offset), 박자, 템포, 조성을 분석하는 AI 모델 단계입니다.
  Omnizart, ByteDance의 AMT 모델 등의 스택을 튜닝하거나, 피아노의 경우 양손 분리(Hand Separation) 모델을 적용해야 가독성 높은 악보가 나옵니다.

## 2. 주요 기능 및 UI/UX 구성

사용자가 인공지능의 한계를 보완하고 실사용하기 좋게 만드는 UI 요소입니다.

- **악기 및 연주 스타일 선택 인터페이스**: 음원을 분석하기 전 사용자가 피아노, 기타(타블라투어), 단선율 악기 등을 직접 선택하게 하여 모델의 정확도를 가이드합니다.
  솔로/앙상블, 클래식/팝 등의 장르 설정을 제공하면 AI가 박자와 조성을 더 쉽게 매칭합니다.
- **내장 악보 에디터 (웹/앱 뷰어)**: AI가 추출한 초안 악보는 기계적인 박자 쪼개기(루바토, 트릴 오류 등)가 발생하기 쉽습니다.
  이를 수정할 수 있는 피아노 롤(Piano Roll) 뷰어와 간단한 음표 수정 에디터 기능을 제공해야 완성도 높은 앱이 됩니다.
- **다양한 내보내기(Export) 포맷**: 사용자가 다른 전문 악보 프로그램(시벨리우스, 피날레 등)에서 2차 가공할 수 있도록 PDF, MIDI, MusicXML 포맷 지원이 핵심 경쟁력입니다.

## 4. 법적 규제 및 저작권 가이드 (중요)

앱 배포 및 서비스 운영 시 반드시 고려해야 할 법적 문제입니다.

- **개인 이용 vs 상업적 이용 명시**: 사용자가 개인이 학습하거나 연습할 목적으로 악보를 추출하는 것은 저작권 침해 위험이 적습니다.
  그러나 추출된 악보를 앱 내에서 공유·배포하거나 판매하는 기능이 들어간다면 원곡 저작권자의 이용 허락이 필요하므로 관련 이용약관을 명확히 해야 합니다.
- **YouTube API 정책 준수**: YouTube 영상을 직접 다운로드하여 파일화하는 방식은 YouTube 서비스 약관(ToS) 위반 소지가 있습니다.
  따라서 많은 서비스들이 영상을 직접 저장하지 않고 실시간 스트림 분석 방식을 취하거나, 이용약관 분쟁을 피하기 위해 사용자가 직접 오디오 파일(MP3)을 업로드하도록 유도하는 서브 루트를 병행합니다.
