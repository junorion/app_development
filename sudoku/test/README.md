# 테스트

저장소에 테스트 프레임워크가 없다. `document` 와 `localStorage` 를 Node 에서 스텁으로
흉내내고, `index.html` 안의 인라인 스크립트를 꺼내 그대로 평가한 뒤 단언한다
(`dom-stub.js`). 앱은 단일 HTML 파일을 유지해야 하므로 소스를 나누지 않고 이 방식을 쓴다.

```sh
node sudoku/test/run.js        # 전체
node sudoku/test/game.test.js  # 하나만
```

| 파일 | 다루는 것 |
|---|---|
| `engine.test.js` | 완성 보드 생성, 해 세기(유일해·갈라지는 배치), 논리 솔버, 난이도별 생성 |
| `game.test.js` | 생성 안정성(난이도별 20회, 상한·하한), 입력·메모·되돌리기, 저장·복원, 기록, 시간 표기, 설명형 힌트, 다국어 문자열 |
| `daily.test.js` | 데일리 결정론(같은 날짜 = 같은 문제), 요일별 난이도, 날짜 키, 기록 저장, 씨앗 함수 |

**스텁을 고칠 때 주의**: 실제 DOM 의 부수효과까지 흉내내야 한다. 예를 들어
`textContent = ""` 는 자식을 비운다 — 그러지 않으면 가짜 실패가 난다.

**이 테스트는 왜 저장소에 있나**: 스크래치 디렉토리에 두었더니 `useHint` 를
`showHint`/`applyHint` 로 나눈 뒤 `engine.test.js` 가 깨진 채로 방치됐다. 다른 파일만
돌려서 알아채지 못했다. 버전 관리 아래 두고 `run.js` 로 한꺼번에 돌린다.
