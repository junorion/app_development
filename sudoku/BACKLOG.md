# 스도쿠 — 백로그

스토어 등록 전 완성도를 올리기 위한 항목. **위에서부터 하나씩** 진행하고, 끝나면
상태를 고치고 커밋 해시를 적는다. 새 항목은 우선순위에 맞는 자리에 끼워 넣는다.

상태: `대기` · `진행중` · `완료` · `보류`

---

## A. 결함 (스토어 등록 전 반드시)

| # | 항목 | 상태 | 비고 |
|---|---|---|---|
| A1 | 기록 지우기에 확인 절차가 없어 한 번 누르면 영구 삭제 | **완료** | 확인 시트 추가. 되돌릴 수 없는 동작에 재사용 가능 |
| A2 | 저장 데이터가 손상되면 앱이 죽고, 데이터가 남아 계속 죽음 | **완료** | `restoreGame()` 이 puzzle·solution·notes 까지 검증하고, 이상하면 버린다 |
| A3 | `S` 가 없을 때 메모 버튼 핸들러에 방어 없음 | **완료** | 현재는 오버레이가 클릭을 막아 드러나지 않던 잠재 결함 |

## B. 진행 중

| # | 항목 | 상태 | 비고 |
|---|---|---|---|
| B1 | **영어 지원** | **진행중** | UI 문자열 + 안드로이드 앱 이름 + 스토어 등록정보 영어판. 기기 언어로 자동 선택 + 수동 전환 |

## C. 다음 후보 (사용자가 고를 때 진행)

| # | 항목 | 왜 |
|---|---|---|
| C1 | 설정 화면 (진동·오류 표시·메모 자동 삭제·타이머 숨기기) | 스도쿠 앱에서 흔히 기대되는 것. 기기·취향 차이를 흡수한다 |
| C2 | 첫 실행 사용법 안내 | 지금은 설명 없이 난이도 선택창부터 뜬다. 메모·힌트·되돌리기를 모르면 기능 절반을 안 쓰게 된다 |
| C3 | 입력 편의 — 숫자 우선 모드, 자동 메모 채우기 | 숫자를 먼저 고르고 칸을 연속 탭. 태블릿에서 훨씬 빠르다 |
| C4 | 접근성 — 스크린리더 지원 | 칸에 읽을 수 있는 이름, 상태 변화 안내. Play 품질 기준에도 걸린다 |

## D. 검토만 하고 넘긴 것

| 항목 | 판단 |
|---|---|
| 앱 이름 "스도쿠" | Play 에서 매우 흔한 이름이라 검색 노출이 불리하다. 다만 이름 변경은 사용자 결정 사항이라 묻고 진행한다 |
| 효과음 | 퍼즐 게임에서 필수가 아니고, 음소거·볼륨 처리까지 하면 비용이 크다 |
| 온라인 순위·일일 퍼즐 | 인터넷 권한이 없다는 점이 이 앱의 강점이다. 넣으면 개인정보처리방침과 데이터 보안 신고가 전부 바뀐다 |

---

## 진행 규칙

- 한 항목이 끝날 때마다 검증(Node 스텁 테스트 + 헤드리스 스크린샷)하고 커밋한다.
- 웹앱을 고치면 안드로이드는 다시 빌드만 하면 된다 (`syncWebApp` 이 자산을 복사한다).
- 스토어에 올릴 AAB 를 다시 만들 때는 `versionCode` 를 올린다.
