# 프로젝트: N-Queens 퍼즐 웹앱 (데모)

## 목표
브라우저에서 바로 실행되는 N-Queens 배치 퍼즐의 **동작하는 데모**를 최대한 빠르게 완성한다.
외부 배포나 최적화는 이번 단계의 목표가 아니다 — "재미있게 플레이 가능한 프로토타입"이 완성 기준이다.

## 핵심 규칙 (게임 로직)
- N×N 격자 보드에 퀸(Queen) N개를 서로 공격할 수 없게 배치하면 성공.
- 퀸은 같은 행, 같은 열, 같은 대각선에 있으면 서로 "공격 중"으로 간주한다.
- 사용자는 칸을 클릭해서 퀸을 놓거나 제거한다 (토글 방식).

## 기능 요구사항
1. **단일 파일 구성**: `index.html` 하나에 CSS와 JS를 인라인으로 포함한다. 외부 라이브러리·프레임워크 사용 금지 (순수 HTML/CSS/JavaScript).
2. **N 선택**: 사용자가 N을 4~10 사이에서 선택할 수 있어야 한다 (드롭다운 또는 슬라이더). N을 바꾸면 보드가 즉시 재생성된다.
3. **보드 UI**: N×N 격자를 체스판처럼 명암이 교차하는 칸으로 그린다.
4. **퀸 배치/제거**: 빈 칸 클릭 → 퀸 배치, 퀸이 있는 칸 클릭 → 제거.
5. **실시간 충돌 표시**: 서로 공격 가능한 퀸이 있으면 해당 칸들을 즉시 빨간색(또는 강조색)으로 표시한다. 클릭할 때마다 재계산.
6. **클리어 조건 및 축하 메시지**: 퀸이 정확히 N개 배치되어 있고 충돌이 하나도 없으면 "성공" 메시지를 화면에 표시한다 (모달, 배너 등 자유).
7. **리셋 버튼**: 보드를 초기 상태로 되돌리는 버튼 제공.

## 있으면 좋지만 필수는 아닌 것 (스트레치, 데모 이후 단계)
- 배치한 퀸 개수 / 남은 퀸 개수 표시
- 소요 시간 타이머
- 힌트 기능 (다음에 놓을 수 있는 안전한 칸 표시)
- 다크모드

## 기술 제약
- 순수 HTML/CSS/JavaScript만 사용 (React, Vue 등 프레임워크 금지 — 이유: 빌드 도구 없이 브라우저에서 파일을 더블클릭해서 바로 실행 가능해야 함).
- 반응형까지는 필요 없음. 데스크톱 브라우저 기준으로만 동작하면 충분.
- 코드는 한 파일 안에서도 읽기 쉽게 함수 단위로 정리해줘 (예: `renderBoard()`, `checkConflicts()`, `checkWin()` 등).

## 완료 기준 (Acceptance Criteria)
- [ ] `index.html`을 더블클릭해서 브라우저로 열면 바로 실행된다.
- [ ] N을 바꾸면 보드 크기가 즉시 바뀐다.
- [ ] 퀸을 놓고 뺄 수 있다.
- [ ] 서로 공격 가능한 퀸이 실시간으로 빨간색으로 표시된다.
- [ ] N개를 충돌 없이 배치하면 성공 메시지가 뜬다.
- [ ] 리셋 버튼이 정상 동작한다.

## 진행 방식
1. 먼저 위 요구사항을 충족하는 최소 버전을 한 번에 구현한다.
2. 완성되면 브라우저에서 직접 열어 동작을 확인하고, 발견되는 버그나 어색한 부분을 알려줄 테니 반복 수정한다.
3. 데모가 만족스러우면 이후 다른 퍼즐(스도쿠, Queens 영역 퍼즐 등)이나 모바일 전환(React Native/Capacitor)을 논의한다.
