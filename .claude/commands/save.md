절차:
1. 이 대화에서 진행한 작업을 정리한다 — 무엇을 만들었는지, 어떤 결정을 왜 내렸는지,
   아직 남은 작업이 무엇인지. 코드 구조나 git 히스토리로 이미 알 수 있는 내용은 제외한다.
2. 메모리 디렉터리의 기존 파일을 먼저 확인한다. 같은 주제를 다루는 파일이 있으면
   새로 만들지 말고 그 파일을 갱신한다.
3. 사실 하나당 파일 하나로, 다음 frontmatter를 갖춘 마크다운 파일로 저장한다:

   ---
   name: <짧은-kebab-case-슬러그>
   description: <한 줄 요약>
   metadata:
     type: user | feedback | project | reference
   ---

   진행 상황·목표·제약은 `type: project`, 사용자가 준 작업 방식 지침은 `type: feedback`을
   쓰고 **Why:** 와 **How to apply:** 줄을 덧붙인다. "다음 주" 같은 상대 날짜는 절대 날짜로
   바꿔 적는다. 관련 메모리는 `[[슬러그]]` 로 연결한다.
4. 같은 디렉터리의 `MEMORY.md` 에 `- [제목](파일명.md) — 한 줄 설명` 형식으로 포인터 한 줄을
   추가한다. 파일이 없으면 새로 만든다. MEMORY.md 에는 본문 내용을 넣지 않는다.
5. 저장한 파일 목록과 각 파일에 담은 내용을 한 줄씩 사용자에게 보고한다.
